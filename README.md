# 📅 Today in History

A beautiful mobile app showing historical events, births, and deaths for any date.

## Features
- 🔍 Search any date
- ⭐ Save favorites
- 📤 Share events
- 🎲 Random facts
- 📱 Mobile friendly

## API
- `/api/events?month=X&day=Y` - Get events for a date
- `/api/random` - Get random event
- `/api/health` - Check status
